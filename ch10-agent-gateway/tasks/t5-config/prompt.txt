config_check.py에 validate(config) 함수를 작성하세요. config는 LiteLLM config.yaml을 읽은 dict입니다. 오류 메시지 문자열의 리스트를 돌려주며, 문제가 없으면 빈 리스트입니다. 규칙: (1) model_list가 없거나 비어 있으면 'model_list is empty' (2) 각 항목에 model_name이 없으면 'entry {i}: missing model_name' (i는 0부터) (3) litellm_params.model이 없으면 'entry {i}: missing litellm_params.model' (4) model 값에 '/'가 없으면 'entry {i}: model must have provider prefix' (5) api_key가 문자열이고 'os.environ/'로 시작하지 않으면 'entry {i}: api_key must use os.environ/' (6) model_name이 중복되면 첫 중복 위치에서 'entry {i}: duplicate model_name {name}'. 같은 항목의 오류는 위 번호 순서로 나열하세요.
